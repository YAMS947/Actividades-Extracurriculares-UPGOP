Términos y Condiciones de Uso de la Plataforma Académica

1. Definiciones

Para efectos de este documento:

“Plataforma”: Sitio web desarrollado con fines académicos para la demostración de técnicas de programación y administración de datos.
“Usuario”: Persona que accede, utiliza o interactúa con la Plataforma.
“Desarrollador”: Autor del proyecto, responsable del diseño y funcionamiento técnico del sistema.
“Datos Personales”: Información ingresada por el Usuario, incluyendo nombre, apellidos, matrícula, usuario y contraseña.

2. Propósito y Alcance del Proyecto

La Plataforma ha sido creada exclusivamente con fines educativos como parte de un proyecto académico. No constituye un sistema oficial de la institución educativa, ni reemplaza plataformas administrativas reales. La información ingresada no se utiliza para trámites escolares, evaluaciones, registros oficiales ni procesos administrativos.

3. Uso Permitido

El Usuario acepta que la Plataforma debe utilizarse únicamente para actividades relacionadas con el aprendizaje y la demostración técnica. Queda prohibido:

• Utilizar la Plataforma para fines comerciales o institucionales
• Intentar acceder a sistemas externos o bases de datos reales
• Manipular el sistema con fines maliciosos
• Proporcionar información personal real sin consentimiento

4. Administración y Naturaleza de los Datos

La Plataforma permite registrar información con fines de demostración técnica. Los datos ingresados pueden ser reales, ficticios o simulados. La Plataforma no valida la información contra sistemas oficiales ni bases de datos institucionales.

No se realiza tratamiento formal de datos personales conforme a la legislación vigente, dado que el proyecto no constituye un servicio real ni un sistema productivo.

5. Seguridad y Limitaciones Técnicas

Debido a su naturaleza académica:

• Puede contener errores o fallos técnicos
• No garantiza disponibilidad continua
• No implementa protocolos avanzados de seguridad
• No asegura cifrado completo de la información
• No está diseñada para manejar datos sensibles o confidenciales

El Usuario reconoce estas limitaciones y utiliza la Plataforma bajo su propio criterio académico.

6. Conservación y Eliminación de Datos

Los datos ingresados:

• No se almacenan con fines institucionales
• No se comparten con terceros
• No se utilizan para análisis externos
• Pueden ser eliminados en cualquier momento por el Desarrollador
• Serán eliminados al finalizar el proyecto académico

7. Derechos del Usuario

El Usuario tiene derecho a:

• Solicitar la eliminación de los datos ingresados
• Utilizar información ficticia en lugar de datos reales
• Abstenerse de proporcionar información personal sensible

8. Responsabilidad del Usuario

El Usuario es responsable de:

• La veracidad de los datos que ingresa
• No proporcionar información personal sin consentimiento
• No utilizar la Plataforma para fines distintos a los académicos

9. Limitación de Responsabilidad del Desarrollador

El Desarrollador no será responsable por:

• El uso indebido de la Plataforma
• La introducción de datos reales sin autorización
• Fallos técnicos, interrupciones o pérdida de información
• Daños derivados del uso de la Plataforma fuera del contexto académico

10. Modificaciones

El Desarrollador puede modificar el contenido, diseño o funcionamiento de la Plataforma sin previo aviso, como parte del proceso de aprendizaje y mejora continua.

11. Aceptación de los Términos

Al utilizar la Plataforma, el Usuario reconoce haber leído y aceptado estos Términos y Condiciones. Si el Usuario no está de acuerdo, deberá abstenerse de utilizar la Plataforma.
